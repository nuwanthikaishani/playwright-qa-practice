# Playwright QA Practice

This repository contains my hands-on practice with **Playwright and JavaScript** for web application test automation.

The main goal of this project is to improve my automation testing skills by creating and executing simple test scenarios.

## Technologies Used

- Playwright
- JavaScript
- Node.js
- Visual Studio Code
- Git & GitHub



## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/nuwanthikaishani/playwright-qa-practice.git
```

**2. Install dependencies**

```bash
npm install
```

**3. Install Playwright browsers**

```bash
npx playwright install
```

**4. Run tests**

```bash
npx playwright test
```

**5. Run tests in headed mode**

```bash
npx playwright test --headed
```

**6. Open the HTML report**

```bash
npx playwright show-report
```
